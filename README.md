# Binance Auto Buy (v3.0)

바이낸스 폰 스캐너(v2.2)를 바탕으로 만든 **별도 APK**입니다. 감시는 한 종류만 두고, 감지된 종목을 USDⓈ-M 선물에서 자동으로 매수합니다. 실제 주문이 나가는 앱이니 소액이나 테스트 환경에서 먼저 확인하세요.

## 동작 요약
- 앱 ID가 `com.example.binanceautobuy`라서 기존 스캐너와 따로 설치됩니다.
- 자동매수를 켜 두면 매일 시작 시각(기본 20:00, 한국 시간)에 세션이 자동으로 시작됩니다.
- 세션 시작 시점의 USDT 잔고가 원금이고, 종목당 금액(원금 × 종목당 비율, 기본 9.5%)은 그때 한 번 정해져 고정됩니다.
- 최대 종목 수(기본 10)까지 진입하고, 손절 난 자리에는 재진입하지 않습니다.
- 이미 산 종목이 다시 감지되거나 슬롯이 가득 찬 뒤의 감지는 알림 없이 무시합니다.
- 진입 직후 감지 봉의 저가를 손절선으로 거래소에 손절 주문(STOP_MARKET, algoOrder)을 겁니다. 손절 주문이 실패하면 그 종목은 바로 시장가로 청산합니다.
- 총 평가손익이 원금 대비 +n%에 도달하면 전량 청산하고 그날 자동매수는 끝납니다.
- 이익 보호선: 총 수익률이 보호선 시작점을 넘은 뒤 최고점에서 하락 폭만큼 내려오면 전량 청산합니다.
- 종료 시각(기본 08:00)에 남은 종목은 전량 청산합니다(설정에서 끌 수 있음).
- 레버리지 기본 1배, 마진은 교차(CROSSED)로 설정합니다.

## 설정 (앱 안 "자동매수 설정")
API Key/Secret, API 주소, 시작·종료 시각, 종목당 비율, 레버리지, 최대 종목 수, 목표 n, 보호선 시작·하락 폭.
API 키는 Android Keystore로 암호화해 저장하고, 저장해 두면 앱을 껐다 켜거나 폰을 재부팅해도 자동매수가 자동으로 이어집니다.

## 백그라운드(도즈) 대응
자동매수가 켜져 있는 동안 포그라운드 서비스가 부분 웨이크락을 잡고 5초마다 점검하며, 5분마다 깨우는 워치독 알람과 부팅 시 자동 재시작이 함께 동작합니다. "백그라운드 유지 설정"으로 배터리 최적화 제외를 꼭 허용하세요.

## 주의
- 이 코드는 아직 빌드와 실제 거래로 검증하지 않았습니다. 먼저 "API 연결 테스트"와 소액으로 확인하세요.
- API 키는 선물 거래 권한만 켜고 출금 권한은 끄세요. 자동매수 전용 계좌 또는 서브계정을 권합니다.
- 일괄 익절, 보호선, 종료 시각 청산은 앱이 직접 판단합니다. 폰이 꺼지거나 앱이 종료되면 실행되지 않을 수 있고, 거래소에 걸린 개별 손절 주문만 계속 작동합니다.
- 테스트 환경을 쓰려면 "API 주소"를 바이낸스 선물 테스트넷 주소로 바꾸세요.

## v3.1 업데이트 (화면 개편)
- 메인 화면 맨 위에서 감시 조건을 수정하고 **START SCANNER**를 누르면 그 조건으로 고정됩니다. 바꾸려면 STOP 후 수정하세요.
- 4시간봉 이상(4h·6h·8h·12h·1d)은 검사 시각(시)을 지정할 수 있습니다. `마감 10분 전` 버튼 제공.
- 메인 화면 아래에는 자동매수 기록(시각 + 내용)만 간단히 표시하고, 가장 최근 매수 종목 앞에 빨간 점이 붙습니다.
- 검사 결과와 최근 검사 로그는 **기록 확인** 안에서만 볼 수 있습니다.
- 우측 상단 톱니바퀴(⚙): 자동매수 설정(API 키·시간·금액), API 연결 테스트, 백그라운드 유지 설정.
- 기록의 5일 고점은 감지 직후부터 진입가 대비 상승분으로 집계합니다(봉 마감을 기다리지 않음).
- 아직 GitHub Actions 빌드와 실제 기기에서 확인하지 않았습니다.

## v3.2 업데이트
- 자동매수 카드에 **진행 상황** 패널 추가: 현재 수익률(원금 대비)·최고 수익률, 목표 수익률까지 진행 바, 보호선 상태(사용 안 함 / 대기 / 작동 중 + 청산선과 현재 여유), 매수 종목별 진입가·손절가, 마지막 갱신 시각.
- 메인 화면 맨 아래에는 자동매수 기록만 표시합니다. 종목 감시 결과와 검사 로그는 기록 확인에서만 봅니다.
- 앱 이름을 Auto Coin으로 바꿨습니다.

## v3.3
- 기록 확인 화면에 **기록 전체 삭제** 버튼 추가(감지 기록 + 최근 검사 로그, 선택 시 자동매수 거래 기록도 삭제).

## v3.4
- **개별 종목 목표 매도**: 설정에 "개별 종목 목표(%)"를 넣으면(예: 3) 각 종목이 진입가 대비 그 %에 닿는 즉시 그 종목만 시장가로 매도하고 손절 주문을 취소합니다. 0이면 사용 안 함.
- 메인 화면 진행 상황의 매수 종목 목록에 **종목별 손익률**(진입가 대비)과 **매도 버튼**을 추가했습니다.
- 매도한 종목은 오늘 세션에서 다시 매수하지 않으며, 최대 종목 수 계산에는 그대로 포함됩니다.

## v3.5
- **일자별 매매 기록**: 하루 사이클(운용 시작~종료)이 끝나면 그날의 매매를 자동 저장합니다(원금·종료 잔고·손익·종료 사유 + 종목별 진입가/청산가/손익률/실제 손익/종료 방식). ⚙ → 일자별 매매 기록에서 누적 손익·수익률·승률 통계와 함께 봅니다. 보관 기간 제한 없음, "기록 전체 삭제"와는 별개로 보관됩니다.

## v3.6
- **보호선 작동 시작 알림**: 수익률이 보호선 시작점에 처음 닿으면 "보호선 작동 시작" 알림을 한 번 보냅니다(세션당 1회, 앱을 재시작해도 중복되지 않음). 알림에는 현재 청산선 값이 표시됩니다.
- **보호선 청산 방식 선택**: 설정의 "청산선을 보호선 시작점에 고정" 체크박스. 끄면(기본) 기존처럼 최고점 − 하락 폭이 청산선이라 최고점이 오르면 청산선도 오릅니다. 켜면 청산선이 시작점 − 하락 폭(예: 시작 5, 폭 4 → +1%)에 고정되고, 최고 수익이 시작점을 넘은 뒤 그 선 이하로 내려오면 청산합니다.
- **10분 수익률 기록**: 메인 화면 진행 상황의 최고 수익률 위 **기록** 버튼을 켜면 10분마다(10분 단위 시각마다 한 번) 현재 총 수익률을 저장합니다. 켜 둔 상태는 다음 날 세션에도 유지되고, 매수한 종목이 있는 동안만 기록합니다. 일자별 매매 기록의 각 날짜를 열면 "10분 수익률 기록" 버튼으로 시각별 수익률과 최고/최저를 볼 수 있습니다.
- **일자별 매매 기록**: 열면 모든 날짜가 접힌 상태로 시작하고, 펼친 날짜는 화면을 다시 그려도 유지됩니다.
- **갱신 주기**: 자동매수 점검과 수익률 갱신을 10초에서 5초 간격으로 줄였습니다(메인 화면은 5초마다 새로 그립니다).
